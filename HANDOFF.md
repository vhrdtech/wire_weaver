## Gotchas
- `SeriesCells` is opt-in (`series(cells)`): types with a hand-written store inside would break otherwise; property types of a cells level need it (ww_si and test `Reading` have it).
- `Staged` carries no lifetime; calls take `src: &dyn CellsSource` (keeps ObserveBatchConsumers at one lifetime). `CellsReader::Ref` holds `&(dyn CellsSource + Sync)`.
- `Staged::flush(src)` also drains the ring.
- Generated `ObserveState::samplers` with cells: `fn samplers<'s, 'c: 's>(&'s mut self)` (plain `'c` failed borrowck).
- A property named `commit`/`is_sampling` would clash with the writer's methods (not handled).
