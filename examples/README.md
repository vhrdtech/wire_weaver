# Examples

The following list of examples is sorted by increasing complexity:

* `minimal_derive` - Simple demo on how to use procedural macros to generate SerDes code automatically
* `minimal_shrink_wrap` - Simple demo on how to use ShrinkWrap wire format directly
* `compare_wire_formats` - Showcases some of the wire format features that result in dense wire representation of data
  structures
* `motor_demo_api`, `motor_demo` - A VESC-like FOC controller on a simulated motor, its ~50 variables observed in three
  rate tiers; see `docs/examples/motor_demo.md`
