# local_trait

> One API used through the generated client and by a plain local struct, with one call site

Depends on `local_trait_api` (the `Counter` trait), `wire_weaver`, `wire_weaver_client`, `wire_weaver_server`,
`ww_device` and `ww_client_server`.
`exercise` is written once against the `Counter` trait. It runs unchanged against `LocalCounter`, a plain struct
called directly, and against the generated `CounterClient` talking to a real or simulated device. `CounterServer` serves the same `LocalCounter` to many clients on `wire_weaver_server`. Its
handlers are generated by `ww_codegen!(.., serve_trait = "local_trait_api::Counter")` and forward to it. The logic
is written once and served remotely only when needed.

See the [main repo](https://github.com/vhrdtech/wire_weaver) for the full picture and
[documentation](https://vhrdtech.github.io/wire_weaver) for the step-by-step guide.
