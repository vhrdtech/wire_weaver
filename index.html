WireWeaver¶

Collection of crates for designing no_std APIs with rich type system, no allocation and dense bit-level wire format.

Plus a whole set of standard types and traits, all written in Rust.

Get started Standard library Examples

What it does¶

  • Wire Format

    Dense zero-copy, no-alloc and no_std wire format. Dynamically sized user-defined types and vectors (on no_std as well). Bit level packing and more.

  • RPC

    Define and call methods with any number of arguments and return type. Call using blocking, async or promise interface.

  • Streams

    Stream data of any type, observe property changes. Both to and from device.

  • Evolution

    Evolve data types and API while still allowing:

    • newer code to work with older devices
    • older code to work with newer devices

  • USB, Ethernet, CAN and more

    Host and device drivers. Plus a framer that can put many small messages in one packet or a bigger message across multiple packets.

  • Standard library

    Numerical, SI, date & time, version and other types. GPIO, I2C, CAN, UART, SPI, logging, firmware update and other traits.

  • Reference and Owned types

    Automatically generate owned types for std usage from referenced ones. &'i [u8] becomes Vec<u8>, MyType<'i> MyTypeOwned, etc.

  • First class MCU support

    Geared towards bare-metal development with FLASH and RAM in mind. No allocation with full feature support.

  • Tooling

    CLI and GUI for debugging. Virtual devices. Introspection and tracing. Dynamic Python clients.
