# keyed

Server of a keyed array (SRV-62): the `keyed_api` Dissector answers `index_of`, `key[i]`, a multi read of all keys and the `keys` stream, from a blocking `no_alloc` server and an async one. The generated and dynamic clients (CLT-72) address flows a device created in shuffled order by their keys. A string key that borrows (API-72), `keyed!(detector by DetectorName<'i>)`, goes through both servers, the client, the local trait and a `serve_trait` server forwarding to a client; its bytes are pinned, being what a tape's `Segment::Key` hashes.
