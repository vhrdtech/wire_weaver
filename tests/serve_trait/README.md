# serve_trait

> Tests of a server generated with `serve_trait` (SRV-49): requests forwarded to the local trait

`Service` implements `serve_trait_api::Served`; `Server` is generated by `ww_codegen!(.., serve_trait =
"serve_trait_api::Served")` with no handler written by hand and served on `wire_weaver_server`. The tests check that
calls of one connection overlap, that a write waits for the calls before it and holds the reads after it, how the
trait's errors reach the client, and that a stream function's items flow through a pump.
