# serve_trait_levels_api

> Test API of a server generated with `serve_trait` for nested levels and resource arrays (CLT-58), exercised by
> `tests/serve_trait`

A nested level, an array of levels with a nested array under a typed index, a level from another crate
(`serve_trait_gauge_api`), an array of properties and an array of streams, with the API and its levels as local
traits: `Plant`, `Desk`, `Unit`, `Channel` and the gauge crate's `Gauge`.
