# thermo_devices

Simulated firmware of every line of the `thermo_api` bench (FEATURES.md EVO-28: a-host-for-several-wire-lines),
on `tests_common`'s in-process link.

Backs `tests/thermo`'s driver tests, the dynamic client's and Python's (`thermo_pytest_devices`, which hosts
the devices behind a ww hub).
