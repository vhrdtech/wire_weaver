# ww_pin_probe

Host side of `ww_pin_diag`: finds shorts, pulls and floating pins on any WireWeaver device serving `PinDiag`, reads
and writes plan files, and drives the live view `ww pins` shows (`ww_std_cli`). Board descriptions and the test
fixtures are in `tests/data`.

Documentation: `docs/std_library/ww_pin_diag.md`.
